# Sireh OS Lite

**Version:** 1.0 Benih (Pre-alpha)

**Tagline:** Diagnose. Monitor. Automate. Anywhere.

Sireh OS Lite is an independent, open-source,
Ubuntu-based lightweight Linux distribution
designed for infrastructure diagnostics,
monitoring and automation.

## Architecture

- Ubuntu LTS base
- USB live-boot
- CLI-first environment
- Optional lightweight desktop
- Sireh Core framework
- Offline-first diagnostic capabilities

## Core Applications

1. OneScan
2. TimeShift
3. EvidencePack
4. PathFinder
