# Sireh Doctor

Flagship diagnostic application for Sireh OS Lite 1.0 Benih.

## Architecture

- gui/: PyQt5 graphical interface
- diagnostics/: Read-only diagnostic engines
- reports/: Evidence and report generation
- tests/: Automated acceptance tests

## Safety

Offline-first and read-only by default.

## Development status

Application structure initialized.
GUI and diagnostic engines are not yet implemented.
